# Like FlpIt? Give .NET a try.

Enjoying FlpIt’s .NET-inspired programming model? Here’s where it comes from.

You don't need to install anything to get started.

## Just want to try C#?

- [.NET Fiddle](https://dotnetfiddle.net/): write, compile, and run C# directly in your browser. No
  installation required.
- [Learn C#](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/): explore the language and its
  features.
- [Explore LINQ](https://learn.microsoft.com/en-us/dotnet/csharp/linq/): see the original LINQ programming model.

## Not ready to leave Python behind?

You don't have to choose one ecosystem over the other.

[CSnakes](https://tonybaloney.github.io/CSnakes/latest/) lets you embed Python code and libraries directly into
.NET applications. It uses Python's C API and generates C# bindings from Python type annotations.

You can keep your existing .NET application, introduce Python where it makes sense, and call Python code
directly from C#, without introducing a REST API or microservice just to connect the two.

## Ready to explore .NET further?

- [Get started with .NET](https://learn.microsoft.com/en-us/dotnet/core/get-started)
- [Download the .NET SDK](https://dotnet.microsoft.com/download)

Enjoy FlpIt. Explore .NET. And don't feel you have to leave either ecosystem behind.
