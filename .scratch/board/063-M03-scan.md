# M03: `scan` / `scan_right`

## 1. Goal
`scan` is `aggregate` that also yields every intermediate state: running totals, cumulative maxima, state machines over events. Python has it as `itertools.accumulate`; LINQ users reach for MoreLINQ `Scan`. `scan_right` is the right-associative, fully buffered counterpart (suffix folds). Both close an obvious gap next to the existing `aggregate`.

## 2. Scope
**In:** `scan(func)`, `scan(func, seed)`, `scan_right(func)`, `scan_right(func, seed)` on `_LinqOps`; own tests; MoreLINQ oracle ops.
**Out:** `pre_scan` (M04, exclusive scan); MoreLINQ `ScanBy` (keyed running state; candidate for a later card); `aggregate` changes (L28).

## 3. Detailed design
### 3.1 Signatures
```python
@overload
def scan(self, func: Callable[[TItem, TItem], TItem]) -> FlpIt[TItem]: ...
@overload
def scan(self, func: Callable[[TAccumulate, TItem], TAccumulate], seed: TAccumulate) -> FlpIt[TAccumulate]: ...

@overload
def scan_right(self, func: Callable[[TItem, TItem], TItem]) -> FlpIt[TItem]: ...
@overload
def scan_right(self, func: Callable[[TItem, TAccumulate], TAccumulate], seed: TAccumulate) -> FlpIt[TAccumulate]: ...
```
MoreLINQ overloads: `Scan(transformation)`, `Scan(seed, transformation)`, `ScanRight(func)`, `ScanRight(seed, func)`: all mapped. **Argument order is `(func, seed)`**, not MoreLINQ's `(seed, func)`, to match flpit's existing `aggregate(func, seed)` and `itertools.accumulate(xs, func, initial=...)`. `seed` uses the `_SENTINEL` default, so `seed=None` is a real seed.

### 3.2 Semantics
`scan` (inclusive, left fold):
- Kind: intermediate, deferred. Buffering: streaming (one accumulator). Short-circuit: unseeded `scan(f).first()` pulls 1 element; seeded `scan(f, s).first()` yields `s` and pulls 0.
- Unseeded: yields `x0, f(x0, x1), f(f(x0, x1), x2), ...`; length `n`; empty → empty; `func` called `n - 1` times.
- Seeded: yields `seed, f(seed, x0), ...`; length `n + 1`; empty → `[seed]`; `func` called `n` times.

`scan_right` (inclusive, right fold, `func(element, accumulator)`):
- Kind: intermediate, deferred. Buffering: **full** (needs the last element first). On first `next()` it consumes the whole source and calls `func` for every step before yielding anything (same as MoreLINQ).
- Unseeded: for `[a, b, c]` yields `f(a, f(b, c)), f(b, c), c`; empty → empty; `n - 1` calls.
- Seeded: yields `f(a, f(b, f(c, s))), f(b, f(c, s)), f(c, s), s`; empty → `[s]`; `n` calls.

Both: validation (eager) `func is None` → `ArgumentNoneError("func")`; `None` elements and `None` seeds are ordinary values; `func` exceptions propagate (for `scan` after the earlier states were yielded; for `scan_right` before any output); re-enumeration repeats the whole computation.

### 3.3 Implementation sketch
```python
def scan(self, func, seed=_SENTINEL):
    _require_callable(func, "func")
    if seed is _SENTINEL:
        def _generator():
            return accumulate(self, func)
    else:
        def _generator():
            return accumulate(chain((seed,), self), func)        # NOT initial=seed: accumulate treats initial=None as "no seed"
    return FlpIt(_FactoryIterable(_generator))

def scan_right(self, func, seed=_SENTINEL):
    _require_callable(func, "func")
    def _generator():
        items = list(self)
        if seed is _SENTINEL:
            if not items:
                return
            acc = items.pop()
        else:
            acc = seed
        out = [acc]
        for x in reversed(items):
            acc = func(x, acc)
            out.append(acc)
        out.reverse()
        yield from out
    return FlpIt(_FactoryIterable(_generator))
```
- `scan`: C-level `accumulate`, O(n) time, O(1) memory. `scan_right`: O(n) time, O(n) memory (source copy + results).
- **FlpList fast path** for `scan_right` (iterate `reversed(data)` without copying): rejected; `func` callbacks could mutate the list mid-computation, and the copy is a cheap C memcpy.

## 4. Tests
- **Own tests** `tests/unit/morelinq/test_scan.py` (from scratch, D7):
  - `scan(add)` over `[]`, `[5]`, `[1, 2, 3, 4]` → `[]`, `[5]`, `[1, 3, 6, 10]`; seeded with `10` → `[10]`, `[10, 15]`, `[10, 11, 13, 16, 20]`.
  - `seed=None` is honoured (`scan(lambda a, x: (a, x), None)` starts with `None`): regression guard against `accumulate(initial=None)`.
  - Last element of `scan(f, s)` equals `aggregate(f, s)` for random inputs (property test with `hypothesis` if available in dev deps, else fixed seeds).
  - Laziness and pull counts: construction does not iterate; seeded `first()` pulls 0, unseeded pulls 1; infinite source + `take(5)` terminates; `func` call counts `n` / `n - 1`.
  - `scan_right`: string example `"abc"` → `['(a+(b+c))', '(b+c)', 'c']`; seeded `[1, 2, 3]` with `0` → `[6, 5, 3, 0]`; empty unseeded → `[]`, empty seeded → `[seed]`; all `func` calls happen before the first yield (tracker); infinite source never yields (guarded by `take` on the *source*, documented).
  - `func=None` raises at call time for both; one-shot vs re-iterable sources; `FlpList` not mutated.
- **Contracts** (auto).
- **Typing**: `assert_type(flp.it([1]).scan(operator.add), FlpIt[int])`; `assert_type(flp.it([1]).scan(lambda acc, x: acc + str(x), ""), FlpIt[str])`; same for `scan_right`.
