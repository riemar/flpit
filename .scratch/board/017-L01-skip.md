# L01: `skip`

## 1. Goal
`Skip(n)` is the most-used LINQ operator still missing (rules.md already lists it as a core intermediate op). It pairs with the existing `take` for paging (`skip(page*size).take(size)`). It is the first operator delivered through the full pipeline (mixin, registry, porting kit, benchmark, harness, docs, skill), so it also validates the foundation work.

## 2. Scope
**In:** `skip(count)` on `_LinqOps` (so `FlpIt`, `FlpList`, `OrderedIt`, `Grouping`). A FlpList fast path using list slicing.
**Out:** `skip_while` (L03), `skip_last` (L05), and the `Range`-based skipping that .NET only expresses via `Take(Range)` (N09).

## 3. Detailed design
### 3.1 Signatures
```python
def skip(self, count: int) -> FlpIt[TItem]: ...
```
### 3.2 Semantics
- Kind: intermediate, deferred. Buffering: streaming. Short-circuit: n/a (it yields the tail).
- `count <= 0` → yields the whole source (.NET: `Skip(-1)` equals `Skip(0)`). No error.
- `count` larger than the source → empty.
- Validation (eager): `count` must be an `int` (`operator.index(count)`); `None` raises `ArgumentNoneError("count")`. `bool` is accepted as an int, as in Python. This is documented, not special-cased.
- The source is not touched until enumeration. Each enumeration of the returned query re-enumerates the source (re-iterable source → re-iterable query; one-shot stays one-shot).
- `skip` on an `OrderedIt` returns `FlpIt` (ordering is applied by the upstream `OrderedIt.__iter__`), so `then_by` is no longer available after it, the same as .NET (`Skip` returns `IEnumerable<T>`).
- Exceptions thrown by the source while skipping propagate at enumeration time.

### 3.3 Implementation sketch
```python
def skip(self, count):
    count = _require_index(count, "count")          # F05 helper
    if count <= 0:
        return FlpIt(self._source())                  # still deferred and re-iterable
    def _generator():
        return islice(iter(self), count, None)
    return FlpIt(_FactoryIterable(_generator))
```
- `islice` is C-level: O(n) time, O(1) memory.
- **FlpList fast path**: `FlpList(...).skip(n)` → `FlpIt(_FactoryIterable(lambda: iter(data[n:])))`. **Rejected** unless a benchmark shows a gain over `islice`: slicing copies O(len−n), and it changes the observable behaviour if the list is mutated between query creation and enumeration (the slice would be taken lazily, so it is equivalent, but there is no gain). Decision: no override; this card documents the measurement in the PR.
- Chained `skip(a).skip(b)` is not collapsed (no observable benefit, keeps the code simple).

## 4. Tests
- **Ported** `tests/nettests/test_skip.py` from `SkipTests.cs` (36 cases). Expected skips:
  - `NO_SPAN_OR_ARRAY`: tests asserting `IList`/`IPartition` internals (e.g. `Skip` on `List<T>` returning a specific iterator type).
  - `INTERNAL_OPTIMIZATION`: `SkipTakeOnIListIsIList`-style tests.
  - `LONG_RUNNING`: none expected; `int.MaxValue` counts run quickly thanks to `islice`.
  - Target: ≥ 75 % of upstream cases ported, not skipped.
- **Own unit tests** (`tests/unit/test_skip.py`):
  - `skip(0)`, `skip(-5)` yield all; `skip(len)` / `skip(len+10)` are empty.
  - Paging composition: `skip(2).take(3)` and `take(5).skip(2)`.
  - On `order_by(...).skip(1)` the ordering is applied before skipping.
  - Passing `None` / `1.5` raises eagerly (`ArgumentNoneError` / `TypeError`).
  - One-shot generator source: second enumeration is empty; re-iterable list: identical results.
- **Contracts** (auto via registry): construction doesn't iterate (`NoIterList`), callbacks lazy, FlpList not mutated.
- **Typing**: `assert_type(flp.lst([1]).skip(1), FlpIt[int])`, and `OrderedIt` input returns `FlpIt`.

## 5. Differential harness
`difftest/specs/skip.toml`: `count ∈ {-3, -1, 0, 1, 2, len-1, len, len+1, 2**31-1}`, sources: empty, singleton, ints with duplicates, strings; probe `enumeration_count` and `elements_pulled` (for `skip(n).first()`, the source pulls n+1 elements). Expected: all MATCH.

## 6. Benchmarks
`tests/benchmarks/test_bench_skip.py`:
- `native`: `list(itertools.islice(data, n, None))`
- `flpit-FlpIt`: `flp.it(data).skip(n).to_list()`; `flpit-FlpList`: `flp.lst(data).skip(n).to_list()`
- sizes 1e3, 1e5; n = size // 2. Target ratio ≤ 1.5× (dominated by `FlpList` construction in `to_list`).

## 7. Docs
- Docstring: `.NET: Enumerable.Skip(count)`; the negative-count rule; streaming; doctest `flp.it(range(5)).skip(2).to_list()` gives `[2, 3, 4]`.
- README operator matrix row (generated). Translation map: `xs[n:]` / `islice(xs, n, None)` / `.Skip(n)` → `.skip(n)`.
