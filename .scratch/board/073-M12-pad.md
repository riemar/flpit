# M12: `pad` / `pad_start`

## 1. Goal
Guarantee a minimum length: fixed-width rows for tables, zero-padding digit lists, aligning ragged records before `zip`. `pad` appends, `pad_start` prepends. Python has `str.ljust`/`rjust` for strings only; for iterables people write `xs + [fill] * (n - len(xs))`, which needs a list.

## 2. Scope
**In:** `pad(width, padding=None, *, padding_selector=...)` and `pad_start(...)` with the same shape, on `_LinqOps` (`FlpIt`, `FlpList`, `OrderedIt`, `Grouping`). A `Sized`-source fast path for `pad_start` (MoreLINQ has the same collection fast path).
**Out:** truncation to `width` (combine with `take`); centring.

**MoreLINQ overload mapping** (3 + 3)
| MoreLINQ | flpit |
|---|---|
| `Pad(width)` → `IEnumerable<T?>` (pads with `default(T)`) | `pad(width)` (pads with `None`) |
| `Pad(width, T padding)` | `pad(width, padding)` |
| `Pad(width, Func<int, T> paddingSelector)` | `pad(width, padding_selector=f)` |
| `PadStart(...)`, same three | `pad_start(...)`, same three |

`padding_selector` is keyword-only: `padding` may legitimately be a callable value (padding a list of functions), so positional callable detection would be ambiguous.

## 3. Detailed design
### 3.1 Signatures
```python
@overload
def pad(self, width: int) -> FlpIt[TItem | None]: ...
@overload
def pad(self, width: int, padding: TPad) -> FlpIt[TItem | TPad]: ...
@overload
def pad(self, width: int, *, padding_selector: Callable[[int], TPad]) -> FlpIt[TItem | TPad]: ...
# pad_start: identical overloads
```
Implementation signature: `pad(self, width, padding=_SENTINEL, *, padding_selector=_SENTINEL)`; omitted `padding` means `None`. New TypeVar `TPad` (when `TPad` is `TItem` the union collapses).

### 3.2 Semantics
- **pad**: Kind: intermediate, deferred. Buffering: streaming (counter only). Yields the whole source, then `max(0, width - n)` padding values. `padding_selector(i)` receives the **result position** `i` (n, n+1, ..., width-1).
- **pad_start**: Buffering: partial (up to `width` elements). Enumerates up to `width` source elements into a buffer; if the source reaches `width`, yields the buffer then streams the rest unchanged; otherwise yields `width - n` paddings, then the buffer. `padding_selector(i)` receives `i = 0 .. width-n-1` (also the result position).
- **`Sized` fast path (pad_start, as MoreLINQ's `TryAsCollectionLike`):** if `src` is `collections.abc.Sized`, `len(src)` is read **at enumeration time**; when `len < width` paddings are yielded first and the source is then streamed without buffering. Values are identical to the buffered path; the only observable difference (padding selector called before the source is enumerated) is the same one MoreLINQ exhibits for collections.
- `width <= n`: the source unchanged (both). `width == 0`: unchanged.
- Validation (eager): `width` via `_require_index`; `width < 0` → `ArgumentOutOfRangeError("width")`; `padding` and `padding_selector` both given → `TypeError`; `padding_selector=None` → `ArgumentNoneError("padding_selector")`. `padding=None` is a valid explicit padding.
- `None` elements are ordinary values. Padding values are not copied (the same object repeats, like `[x] * k`).
- Re-enumeration re-runs the source (and re-reads `len` for the fast path). Exceptions propagate at enumeration.

### 3.3 Implementation sketch
```python
def pad(self, width, padding=_SENTINEL, *, padding_selector=_SENTINEL):
    width = _require_non_negative(_require_index(width, "width"), "width")
    fill = _padding_fn(padding, padding_selector)          # validates the pair; None means constant
    src = self._source()
    def _generator():
        n = 0
        for n, item in enumerate(src, 1):                   # C-level counter
            yield item
        if n < width:
            if fill is None:
                yield from repeat(None if padding is _SENTINEL else padding, width - n)
            else:
                yield from map(fill, range(n, width))
    return FlpIt(_FactoryIterable(_generator))
```
- `pad` on the default path can be `chain(src, repeat(...))`-like, but `n` must be known; `enumerate` keeps it C-level. O(n) time, O(1) memory.
- `pad_start`: `if isinstance(src, Sized) and (k := width - len(src)) > 0: yield paddings(0..k-1); yield from src` else `head = list(islice(it, width))`, then branch as in §3.2. O(n) time, O(width) memory on the buffered path.
- **FlpList**: covered by the `Sized` path through `_source()`; no override.

## 4. Tests
- **Ported:** none (D7). Checklists: `PadTest.cs` (12: negative width, laziness, wide/equal/narrow source with default, explicit and dynamic padding; value- and reference-type variants) and `PadStartTest.cs` (33: same matrix with collection vs sequence sources, plus "uses collection count at iteration time"). Mapping:
  - covered by own tests: every width/padding combination, laziness, collection count read at iteration time.
  - `NO_VALUE_TYPES`: value-type `default(T)` padding (`0`) cases; own tests assert `None`.
  - Target: 100 % of applicable behaviours.
- **Own unit tests** (`tests/unit/morelinq/test_pad.py`, `test_pad_start.py`, both `flp_type`s plus the `non_collection` fixture):
  - `[1, 2].pad(4)` → `[1, 2, None, None]`; `pad(4, 0)`; `pad(5, padding_selector=lambda i: i * 10)` → `[1, 2, 20, 30, 40]`.
  - `pad_start` mirror: `[None, None, 1, 2]`, selector indexes `0..k-1`.
  - `width` in `{0, n, n+1, -1, None, 1.5}`; both `padding` and `padding_selector` → `TypeError`.
  - `pad_start` on a list mutated after query creation uses the new length; on a generator buffers at most `width` items (counting source) and streams the tail.
  - `padding=None` explicit, callable as padding value, selector call count = number of paddings.
  - One-shot vs list re-enumeration.
- **Contracts:** auto via registry.
- **Typing:** `assert_type(flp.it([1]).pad(3), FlpIt[int | None])`, `pad(3, 0)` → `FlpIt[int]`, `pad(3, "x")` → `FlpIt[int | str]`, selector form.

## 6. Benchmarks
`tests/benchmarks/test_bench_pad.py`, sizes 1e3 / 1e5, `width = size + size // 10`:
- `native` pad: `list(chain(data, repeat(0, width - len(data))))`; pad_start: `[0] * (width - len(data)) + data`.
- `flpit-FlpIt` / `flpit-FlpList`: `pad(width, 0).to_list()`, `pad_start(width, 0).to_list()`; an extra group feeds a generator source to `pad_start` (buffered path).
- Target ratio ≤ 1.5× (pad, streaming), ≤ 1.3× (pad_start).
