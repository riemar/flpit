# M05: `lag`

## 1. Goal
`lag(k)` pairs every element with the element `k` positions earlier: deltas between consecutive readings, "change since previous row", moving comparisons. Python users currently hand-roll `zip(xs, xs[1:])` (lists only) or a `deque`. It is the first of the Phase 3 "neighbour" operators after `pairwise`/`window`, and its twin `lead` (M06) reuses the same skeleton.

## 2. Scope
**In:** `lag(offset, result_selector=..., *, default=None)` on `_LinqOps` (so `FlpIt`, `FlpList`, `OrderedIt`, `Grouping`). Tuple result when no selector is given.
**Out:** negative/zero offsets as an alias for `lead` (MoreLINQ rejects them on purpose, so do we); multi-offset lags (`lag(1, 2, 3)`), use `window` (M02).

**MoreLINQ overload mapping**
| MoreLINQ | flpit |
|---|---|
| `Lag(offset, Func<T, T?, TResult>)` | `lag(offset, result_selector)` (lagged value `None` before the offset) |
| `Lag(offset, T defaultLagValue, Func<T, T, TResult>)` | `lag(offset, result_selector, default=value)` |
| (none) | `lag(offset)` / `lag(offset, default=value)` → `(current, lagged)` tuples, Python convenience mirroring `zip` |

## 3. Detailed design
### 3.1 Signatures
```python
@overload
def lag(self, offset: int) -> FlpIt[tuple[TItem, TItem | None]]: ...
@overload
def lag(self, offset: int, *, default: TDefault) -> FlpIt[tuple[TItem, TItem | TDefault]]: ...
@overload
def lag(self, offset: int, result_selector: Callable[[TItem, TItem | None], TResult]) -> FlpIt[TResult]: ...
@overload
def lag(
    self, offset: int, result_selector: Callable[[TItem, TItem | TDefault], TResult], *, default: TDefault
) -> FlpIt[TResult]: ...
```
`TDefault` is a new module-level TypeVar (shared with M06 and the D5 `*_or_default` cards).

### 3.2 Semantics
- Kind: intermediate, deferred. Buffering: partial (at most `offset` elements held). Short-circuit: n/a, but strictly streaming: the i-th result is produced after exactly i+1 source pulls.
- The selector is called as `result_selector(current, lagged)` (current first, same order as MoreLINQ). For the first `offset` elements `lagged` is `default`.
- Validation (eager, at call time): `offset = _require_index(offset, "offset")`; `offset <= 0` raises `ArgumentOutOfRangeError("offset")`; an explicit `result_selector=None` raises `ArgumentNoneError("result_selector")`. `default` may be any value, including `None`.
- `offset >= len(source)`: every element is paired with `default`; no error. Huge offsets (`2**31 - 1`) cost nothing (lazy `repeat`).
- Empty source → empty. `None` elements are ordinary values (a lagged `None` is indistinguishable from the default `None`; pass `default=` a sentinel if that matters).
- Re-enumeration re-enumerates the source; one-shot stays one-shot. Source and selector exceptions propagate at enumeration time, after all earlier results were yielded.

### 3.3 Implementation sketch
```python
def lag(self, offset, result_selector=_SENTINEL, *, default=None):
    offset = _require_positive_index(offset, "offset")      # F05 helper (index + > 0)
    _require_callable_or_sentinel(result_selector, "result_selector")
    def _generator():
        current, behind = tee(self)
        lagged = chain(repeat(default, offset), behind)
        if result_selector is _SENTINEL:
            return zip(current, lagged)
        return map(result_selector, current, lagged)
    return FlpIt(_FactoryIterable(_generator))
```
- All C-level (`tee`, `chain`, `repeat`, `zip`/`map`); `zip` pulls `current` first, so a finished source ends the loop before `lagged` is touched. O(n) time, O(min(offset, n)) memory (the `tee` buffer holds the gap).
- **FlpList fast path**: two plain iterators over the backing list instead of `tee` (`zip(data, chain(repeat(default, k), data))`). Results and callback calls are identical (operators never mutate a FlpList). Adopt only if the benchmark shows ≥ 15 % gain at 1e5; record the measurement in the PR.

## 4. Tests
- **Ported:** none (D7). `LagTest.cs` (10 cases) is used as a behaviour checklist only; own tests cover each applicable behaviour:
  - covered: laziness, negative and zero offset rejected, explicit default, implicit default, offset > length, offset 1 and 2 values.
  - `NO_VALUE_TYPES`: `TestLagImplicitDefaultValue` relies on `default(int) == 0`; the own test asserts `None` instead.
  - `NO_NULLABLE_DISTINCTION`: `TestLagWithNullableReferences` / `...NonNullableReferences` are compile-time nullability checks; replaced by a typing test.
  - Target: 100 % of applicable behaviours have an own test.
- **Own unit tests** (`tests/unit/morelinq/test_lag.py`, both `flp_type`s):
  - `lag(1)` tuples; `lag(2, lambda c, p: c - p, default=0)` on `[1, 2, 3, 4]` → `[1, 2, 2, 2]`.
  - `offset` larger than the source, equal to it, and `2**31 - 1`.
  - `offset` in `{0, -1}` raises `ArgumentOutOfRangeError` at call time (source never touched); `None` / `1.5` raise `ArgumentNoneError` / `TypeError`.
  - Pull counting: after taking i results the source was pulled exactly i times (`counting_source` fixture).
  - Selector receives `(current, lagged)` in that order; a selector exception surfaces at the right element.
  - `None` elements and `default=None` vs `default=sentinel`.
  - One-shot generator vs list re-enumeration; `order_by(...).lag(1)` orders first.
- **Contracts:** auto via registry (deferral, one-shot, no FlpList mutation, partial buffering bound = `offset`).
- **Typing** (`tests/typing/test_types_lag.py`): `assert_type(flp.lst([1]).lag(1), FlpIt[tuple[int, int | None]])`, `lag(1, default=0)` → `FlpIt[tuple[int, int]]`, selector form → `FlpIt[TResult]`.

## 5. Differential harness
`difftest/specs/lag.toml`, oracle `difftest/oracle/Operators/Lag.cs` calling `MoreEnumerable.Lag` from the pinned `morelinq` NuGet package. Domains: `offset ∈ {-1, 0, 1, 2, len-1, len, len+1, 2**31-1}`; sources: empty, singleton, ints with duplicates, strings with nulls; selector = tuple builder; `default ∈ {omitted, 0, "x"}`. Probes: values, exception type at call time, `elements_pulled` after `take(k)`. Expected classifications: all MATCH except int sources with omitted default (`default(int) = 0` vs `None`): the spec passes `default=0` for value-type domains, so they MATCH too; reference-type domains compare `null`↔`None`.

## 6. Benchmarks
`tests/benchmarks/test_bench_lag.py`, sizes 1e3 / 1e5, `offset = 1`:
- `native`: `list(map(operator.sub, data, chain(repeat(0, 1), data)))` (the idiom a reviewer writes for a list; `itertools.pairwise` does not give the leading default).
- `flpit-FlpIt`: `flp.it(data).lag(1, operator.sub, default=0).to_list()`; `flpit-FlpList`: same on `flp.lst(data)`.
- Target ratio ≤ 1.5× (streaming); the FlpIt path pays for `tee`.

## 7. Docs
- Docstring: summary; `MoreLINQ: MoreEnumerable.Lag(offset, [defaultLagValue,] resultSelector)`; Args (`offset > 0`, `result_selector(current, lagged)`, `default`); Raises (`ArgumentOutOfRangeError`, `ArgumentNoneError`); `Execution:` deferred, streaming with a buffer of `offset` elements.
- Doctest:
  ```python
  >>> flp.it([1, 2, 3, 4]).lag(1).to_list()
  [(1, None), (2, 1), (3, 2), (4, 3)]
  >>> flp.it([1, 2, 3, 4]).lag(2, lambda cur, prev: cur - prev, default=0).to_list()
  [1, 2, 2, 2]
  ```
- Translation map: `.Lag(1, (c, p) => ...)` (MoreLINQ) / `zip(xs, chain([d], xs))` / `pandas.Series.shift(1)` → `.lag(1, f, default=d)`.
- Intentional deviations (README): tuple result when no selector; implicit default is `None`, not `default(T)` (so `0` for ints in .NET).

## 11. Risks / open questions
- Keyword name: `default` (D5 convention, also `next(it, default)`) versus MoreLINQ's `defaultLagValue`/a `default_value` keyword. Proposal: `default`; decide once for M05, M06 and M14 (`fillvalue` stays, it mirrors `itertools`).
- `tee` keeps a reference to buffered items until both branches pass them; for `offset` close to `len`, memory is O(n). Acceptable and documented.
